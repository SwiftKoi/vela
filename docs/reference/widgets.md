# Widget reference

Every widget a screen can write, and the props it takes.

Generated by `vela doc widgets` from the prop schemas in `vela-ui` — the same definition the checker and the completion list read (`SCREENS.md §9`), so a prop on this page is a prop the compiler knows. Do not edit it by hand: a test fails when it is out of date.

## Props every widget takes

A `*` marks a prop a screen has to give. A prop that takes *a label or screen* is resolved by the checker rather than read as a literal, so a typo is a diagnostic rather than a silent nothing.

| prop | takes | | meaning |
| --- | --- | --- | --- |
| `size` | a size |  | Fixed size; `auto` follows the content. |
| `min` | a size |  | Smallest size this node may take. |
| `max` | a size |  | Largest size this node may take. |
| `grow` | a number |  | Flex weight along the parent's main axis. |
| `anchor` | an anchor |  | Where this node sits inside its parent's slot. |
| `at` | a word |  | Position, scale, and alpha offset. |
| `id` | a word |  | A stable name, so an edit keeps this node's state. |
| `style` | a word |  | A `style` declaration to draw with. |
| `background` | a word |  | A fill colour behind this node, as a theme token (`theme.bg`). |
| `stretch_x` | a word |  | Fill the parent along the horizontal axis. |
| `stretch_y` | a word |  | Fill the parent along the vertical axis. |

## Widgets

### `box`

It is a container, and takes exactly one child.

Adds:

| prop | takes | | meaning |
| --- | --- | --- | --- |
| `pad` | a number |  | Space inside the container's edges. |
| `align` | an anchor |  | Where children sit in the space they are given. |

### `button`

It can be focused, and takes exactly one child.

Adds:

| prop | takes | | meaning |
| --- | --- | --- | --- |
| `pad` | a number |  | Space inside the container's edges. |
| `align` | an anchor |  | Where children sit in the space they are given. |
| `action` | a word |  | What activating this does: `action jump(forest.confession)`. |
| `enable_if` | a word |  | A condition; the widget is inert when it does not hold. |
| `label` | text |  | What a screen reader announces, when the content is not enough. |
| `value` | a word |  | What a `bar`, `slider`, or `input` shows or edits. |
