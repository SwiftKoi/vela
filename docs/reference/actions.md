# Action reference

Every action a screen can attach to a widget.

Generated by `vela doc actions` from the action registry in `vela-ui`. Arguments are typed by the same schema a widget's props use, so an action and a prop of the same name take the same kind of value. Do not edit this page by hand: a test fails when it is out of date.

## `jump(label)`

Transfer to a label, replacing the current one.

| argument | takes | meaning |
| --- | --- | --- |
| `label` | a label or screen | Where to go. |

## `call(label)`

Transfer to a label, remembering where to come back to.

| argument | takes | meaning |
| --- | --- | --- |
| `label` | a label or screen | Where to go. |

## `return()`

Return from a `call`.

## `set(name, value)`

Assign a variable.

| argument | takes | meaning |
| --- | --- | --- |
| `name` | a word | The variable to write. |
| `value` | a word | What to write into it. |

## `toggle(name)`

Flip a boolean.

| argument | takes | meaning |
| --- | --- | --- |
| `name` | a word | The boolean to flip. |

## `play(channel, source)`

Start a sound.

| argument | takes | meaning |
| --- | --- | --- |
| `channel` | a word | Which channel. |
| `source` | an asset | What to play. |

## `stop(channel)`

Stop a sound.

| argument | takes | meaning |
| --- | --- | --- |
| `channel` | a word | Which channel. |

## `open_screen(screen)`

Show a screen above this one.

| argument | takes | meaning |
| --- | --- | --- |
| `screen` | a label or screen | Which screen. |

## `close_screen()`

Dismiss the screen this action is in.

## `wait(seconds)`

Do nothing for a while, without blocking a frame.

| argument | takes | meaning |
| --- | --- | --- |
| `seconds` | a number | How long. |

## `quit()`

Leave the story.

## `quick_save()`

Save to the quick slot.

## `quick_load()`

Load the quick slot.
