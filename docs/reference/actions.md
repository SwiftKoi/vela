# Action reference

Every action a screen can attach to a widget.

Generated by `vela doc actions` from the action registry in `vela-ui`. Arguments are typed by the same schema a widget's props use, so an action and a prop of the same name take the same kind of value. Do not edit this page by hand: a test fails when it is out of date.

## `jump(label)`

Transfer to a label, replacing the current one. Declared, not dispatched yet: the runtime does not act on it.

| argument | takes | meaning |
| --- | --- | --- |
| `label` | a label or screen | Where to go. |

## `call(label)`

Transfer to a label, remembering where to come back to. Declared, not dispatched yet: the runtime does not act on it.

| argument | takes | meaning |
| --- | --- | --- |
| `label` | a label or screen | Where to go. |

## `return()`

Return from a `call`. Declared, not dispatched yet: the runtime does not act on it.

| argument | takes | meaning |
| --- | --- | --- |
| `name` | a word | The variable to write. |
| `value` | a word | What to write into it. |

## `open_screen(screen)`

Show a screen above this one.

| argument | takes | meaning |
| --- | --- | --- |
| `screen` | a label or screen | Which screen. |

## `close_screen()`

Dismiss the screen this action is in.

## `hide(screen)`

Dismiss a named screen, wherever it sits in the stack.

| argument | takes | meaning |
| --- | --- | --- |
| `screen` | a label or screen | Which screen to dismiss. |

## `wait(seconds)`

Do nothing for a while, without blocking a frame. Declared, not dispatched yet: the runtime does not act on it.

| argument | takes | meaning |
| --- | --- | --- |
| `seconds` | a number | How long. |

## `quit()`

Leave the story.

## `quick_save()`

## `quick_load()`

## `rollback()`

Step back one command, replaying from the nearest snapshot.

## `skip()`

Fast-forward until something needs an answer. Declared, not dispatched yet: the runtime does not act on it.
