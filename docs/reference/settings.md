# Settings reference

Every setting a screen can write, and whether the engine obeys it yet.

Generated by `vela doc settings` from the vocabulary in `vela-ui::settings`. A name outside this list is `E5020` where it is written, and `read` is the honest half of a list that runs ahead of its systems: a setting nothing obeys says so here rather than looking like a control that works. Do not edit this page by hand: a test fails when it is out of date.

| setting | holds | default | what it is |
| --- | --- | --- | --- |
| `text_speed` | a number | `0` | How fast dialogue types out, in characters per second. `0` is instant, which is what most readers want and what a keyboard-only player needs. Declared, not read yet: nothing in the engine obeys it. |
| `auto_forward` | true or false | `false` | Whether the story advances on its own, without a press. Declared, not read yet: nothing in the engine obeys it. |
| `auto_forward_time` | a number | `15` | How many seconds a line waits before auto-forward moves on. Declared, not read yet: nothing in the engine obeys it. |
| `skip_unseen` | true or false | `false` | Whether skipping continues through text the player has not read yet. Declared, not read yet: nothing in the engine obeys it. |
| `skip_after_choices` | true or false | `true` | Whether skipping survives a menu the player answered. Declared, not read yet: nothing in the engine obeys it. |
| `transitions` | true or false | `true` | Whether transitions are shown at all. Declared, not read yet: nothing in the engine obeys it. |
| `display_mode` | window, fullscreen | `window` | How the game's window is shown. Declared, not read yet: nothing in the engine obeys it. |
