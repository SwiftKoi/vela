# Decision records

Short, dated records of decisions that are expensive to reverse or easy to re-litigate. Each
one states the context, the decision, its consequences, and what was rejected — because "why not
the obvious alternative?" is the question a future reader always has.

`ARCHITECTURE.md §7` holds the small decisions inline. A decision graduates to a file here when
it becomes long-form or gets revisited.
