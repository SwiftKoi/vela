# Diagnostic code registry.
#
# Format: <code>|<severity>|<title>
#   code      `E` error, `W` warning, `L` lint, followed by four digits
#   severity  error | warning | lint, and it must agree with the code's letter
#
# Codes are permanent: never reused, never renumbered. Ranges are reserved by phase,
# so a new diagnostic has an obvious home. See docs/spec/LANGUAGE.md §8.
#
# The file must stay sorted by code, and every code must be referenced by a test.
